# Demo React Code Files Storage

This folder (`frontend/src/demo/`) is reserved for storing separate demo code files, experimental components, and test snippets for React.

### How to use:
1. Place your isolated demo components or snippets here (e.g. `DemoCard.jsx`, `DemoChart.jsx`, `TestView.jsx`).
2. You can import them directly in any part of the app or in routes:
   ```jsx
   import MyDemo from './demo/MyDemo';
   ```
