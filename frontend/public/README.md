# Multiix Professional Logo Pack

Contains 60 app/service SVG icons and 2 Multiix brand SVGs.

- `app-logos/`: feature logos, consistent rounded-square style and colors.
- `brand/multiix-horizontal.svg`: horizontal logo with name outside the symbol.
- `brand/multiix-symbol.svg`: symbol-only logo.

SVG files are scalable and editable. Use directly in websites, React/Vite, Figma, or design tools.
